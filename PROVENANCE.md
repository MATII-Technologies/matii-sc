# Provenance and licensing

**Clean-room.** Phase's own CLI (`phasehq/cli`) and Kubernetes operator
(`phasehq/kubernetes-secrets-operator`) are **GPL-3.0**. Nothing in this repository
is derived from them, and their source was not consulted. The wire protocol and
cryptography were implemented from:

* the MIT-licensed console (`console/backend/api/utils/crypto.py`,
  `api/views/*`, `api/serializers.py`, `api/auth.py`), which is the server side of
  the protocol, and
* libsodium's public documentation (crypto_kx, XChaCha20-Poly1305, BLAKE2b).

Phase's MIT SDKs (`golang-sdk`, `node-sdk`, `python-sdk`) were not used either.

Compatibility is verified with test vectors generated by the console backend
(`go/matii/testdata/vectors.json`) and an end-to-end test that runs the `matii` CLI
against a live console backend (`console/backend/tests/matii/db/test_cli_interop.py`).

**Third-party dependencies:** `golang.org/x/crypto` and `golang.org/x/sys` (BSD-3-Clause);
`libsodium-wrappers` (ISC).
